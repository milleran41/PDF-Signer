Главная страница

Выберите документ, который нужно заполнить, а затем добавьте текст и подпись.

Поддерживаются PDF, DOCX и изображения. Всё обрабатывается локально в браузере.

Нравится BRINO?

Если программа помогает вам заполнять документы и экономить бумагу, пожалуйста, поставьте оценку или оставьте отзыв в Microsoft Edge Add-ons.

Справка

Как пользоваться

  1. Нажмите «Добавить файлы» или выберите документ на главной странице. Можно добавлять PDF, DOCX и изображения.
  2. Выберите нужный лист слева. Ненужные листы можно удалить крестиком на миниатюре.
  3. Выровняйте скан поворотом и при необходимости настройте общий размер документа.
  4. Нажмите «Добавить текстовое поле» или кликните по документу. Поле можно перетаскивать и менять шрифт, цвет, подъём и интервал.
  5. Создайте или выберите сохранённую подпись, вставьте её в документ и нажмите «Сохранить документ».

Назначение кнопок

Добавить файлы

Загружает один или несколько документов в редактор.

Добавить текстовое поле

Добавляет новое поле в центр видимой части документа. Его можно перетащить в нужное место.

Скрыть данные

Добавляет видимый маркер поверх конфиденциальной записи. Это не меняет исходный документ и не предназначено для незаметной подмены текста.

Очистить

Удаляет все загруженные листы и возвращает главную страницу.

Размер документа

Увеличивает или уменьшает сам документ для удобной работы и сохранения.

Поворот

Слегка поворачивает криво отсканированный документ.

Ориентир

Показывает красную линию, по которой удобно выравнивать скан.

Создать подпись

Открывает окно создания подписи: можно нарисовать, загрузить файл или вставить из буфера.

Мои подписи

Открывает страницу с сохранёнными шаблонами подписей.

Подписи:

Показывает сохранённые подписи для быстрой вставки в документ.

Сохранить документ

Сохраняет весь загруженный документ целиком в выбранном формате.
